# Vox Studio 1.0.0

The first release of Vox Studio: a free, local, open-source agentic video editor for Apple Silicon
Macs that turns a link or your footage into Vox-style 9:16 clips on an editable timeline.

## What is in it

- **Quick clips**: paste a YouTube, Instagram or TikTok link (or choose a file), pick how many clips
  and how long, and get captioned 9:16 clips, one sequence tab each. No AI model needed.
- **Editor**: multi-track timeline (trim, split, ripple, links, transitions, text, scenes), live
  preview, subtitle fixing, styles gallery (`base`, `vox`), snapshots, full undo history.
- **Agent panel**: ask for edits in plain words. The agent works on the timeline you see; every run
  is one undoable change set ("Undo this run"). "Make clips from URL", "Add style beats",
  "Confirm plan first", tighten cards for pauses and fillers, a todo list and an activity log.
- **Models you choose** (Settings): Apple on-device and Ollama run on your Mac with no key; OpenRouter,
  OpenCode Zen, Claude, OpenAI, Gemini or any OpenAI-compatible server with your own key (stored in
  the macOS Keychain, shown only masked). Each model is tested before it gets a role; each run has a
  budget.
- **Export**: MP4 (with a loudness and audio check), SRT/VTT captions, editable OTIO timeline.
- **`vox` command line** for the same engine (Vox Studio → Install vox Command…).

## Install

Download `Vox-Studio-1.0.0-arm64.dmg` below. Needs an Apple Silicon Mac with macOS 14 or later
(Apple on-device models need macOS 26 with Apple Intelligence on).

1. Open the `.dmg` and drag **Vox Studio** to **Applications**.
2. Open Vox Studio. The app is ad-hoc signed, not notarized, so macOS blocks the first launch
   ("Apple could not verify…"). Click **Done**, open **System Settings → Privacy & Security**, scroll
   to the message about Vox Studio and click **Open Anyway**, then confirm with your password or
   Touch ID. Or in Terminal: `xattr -dr com.apple.quarantine "/Applications/Vox Studio.app"`.
3. On the setup screen click **Install all** (pinned tools, SHA-256 checked, about 3 GB with the
   Python environment). ffmpeg comes from Homebrew (`brew install ffmpeg`); the setup screen shows
   the commands if it is missing.

Full steps: [README](https://github.com/aliefauzan/open-editor#install-from-the-dmg).

## Known limits

- Not notarized: the Gatekeeper step above is needed once.
- Instagram and TikTok posts that need a login work only with Settings → Tools → "Use browser
  cookies" (off by default) or by choosing the downloaded file.
- Cloud models send project content (transcripts, frames, your messages) to the provider you chose.
- Cloud providers (OpenRouter and the others) were checked with mocks only before this release; the
  live checks ran with Apple on-device and Ollama. Small local models place fewer style beats than a
  cloud model (the speaker stays on screen longer).
- The Apple on-device model works as the `fast` role (scoring quick clips), not as the editor.
